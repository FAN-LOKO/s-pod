Семья и дети

8 программ

Создание семьи

  • Психология
  • Юрист
  • Мероприятия

Программа для сотрудников, которые хотят создать семью или готовятся к браку. Психологические консультации по вопросам отношений, помощь в знакомствах через мероприятия и клубы по интересам, юридическая поддержка по семейному праву, льготы для молодожёнов.

Для когоМолодые специалисты, работники смен, вахтовики

Навстречу друг другу

  • Семья
  • Психолог
  • Юрист

Поддержка на этапе до развода. Консультации семейного психолога, юридические консультации по семейному праву. Помощь восстановить отношения или цивилизованно пройти период расставания.

Для когоСотрудники в кризисе семейных отношений

Поддержка одиноких родителей

  • Родители
  • Психология

Программа для сотрудников, воспитывающих детей без второго родителя. Психологическая поддержка, юридические консультации, помощь в решении бытовых и финансовых вопросов.

Для когоОдинокие мамы и папы в коллективе

Образование детей

  • Дети
  • Образование

Подбор учебных заведений: школы, колледжи, вузы, дополнительное образование. Консультации по поступлению, подготовке и выбору траектории обучения ребёнка.

Для когоРодители школьников и абитуриентов

Профориентация ребёнка

  • Дети
  • Карьера

Помощь в профессиональном самоопределении детей сотрудников. Тестирование, консультации профориентолога, знакомство с профессиями, в том числе инженерными и рабочими специальностями.

Для когоСотрудники с детьми 12–18 лет

Равные права при разводе

  • Развод
  • Семейное право

Семейный юрист при разводе — независимо от того, по чьей инициативе расторгается брак. Помощь в разделе имущества, определении места жительства детей, алиментах.

Для когоСотрудники в процессе расторжения брака

Забота о родителях

  • Семья
  • Уход

Программа поддержки сотрудников, ухаживающих за пожилыми родителями. Консультации по социальному обслуживанию, льготам, медицинскому уходу, юридическим вопросам.

Для когоСотрудники старшего возраста и их семьи

В декрете — вместе

  • Декрет
  • Возвращение

Поддержка сотрудников в отпуске по беременности и родам или по уходу за ребёнком до 3 лет. Юридические консультации, психологическая поддержка, сохранение квалификации, содействие возвращению на работу.

Для когоСотрудницы и сотрудники в декретном отпуске

Быт и жильё

5 программ

Жилищная программа

  • Ипотека
  • Субсидии
  • Вычеты

Помощь специалистов по жилью: разбор ипотечных программ, субсидий, служебного жилья, налоговых вычетов. Консультации по покупке, аренде и улучшению жилищных условий сотрудников и их семей.

Для когоСотрудники, переезжающие на новую площадку, молодые семьи

Личный помощник и «Мастер на час»

  • Быт
  • Экономия времени

Сервис решения бытовых вопросов: вызов мастера для ремонта, сантехника, электрика, мелкий бытовой ремонт. Экономит время и снижает бытовой стресс сотрудников.

Для когоСотрудники с высокой загрузкой и сменным графиком

Автомобильная программа и «Помощь на дороге»

  • Авто
  • Эвакуация

Помощь с автомобилем: подбор, покупка, обслуживание, юридические вопросы. Сервис «Помощь на дороге» — эвакуация, техническая помощь, консультации в дороге.

Для когоСотрудники, добирающиеся до работы на личном транспорте

Загородный уикенд

  • Отдых
  • Семья

Семейный загородный отдых от партнёров: базы отдыха, санатории, экотуризм. Скидки и специальные условия для сотрудников компании.

Для когоСотрудники с семьями

Забота о домашнем питомце

  • Питомцы
  • Партнёры

Помощь в заботе о домашних животных: ветеринарные консультации, поиск клиник, передержка, зоотовары от партнёров.

Для когоВладельцы домашних животных

6 программ

Возврат налогов

  • Налоги
  • Вычеты

Помощь в получении налоговых вычетов: за обучение, лечение, покупку жилья, ИИС. Консультации по декларированию доходов, подготовка документов.

Для когоВсе категории сотрудников

Правовой выход из долгов

  • Долги
  • Банкротство
  • Защита

Программа для сотрудников с долговой нагрузкой. Консультации по банкротству, реструктуризации долга, защите от давления коллекторов, сохранению прожиточного минимума.

Для когоСотрудники с кредитной нагрузкой

Сопровождение при исполнительном производстве

  • Приставы
  • Юрист

Правовая поддержка при исполнительных производствах. Юридические консультации, обжалование незаконных действий приставов, снижение взыскания, сохранение прожиточного минимума, реструктуризация долга.

Для когоСотрудники, столкнувшиеся с взысканиями

Юридическая помощь при банкротстве

  • Банкротство
  • Суд

Полное сопровождение процедуры банкротства физического лица. Консультации юриста, подготовка документов, представительство в суде, защита интересов сотрудника.

Для когоСотрудники с неподъёмной долговой нагрузкой

Кредитный рейтинг

  • Финансы
  • БКИ

Программа повышения кредитного рейтинга. Консультации по кредитным историям, помощь в получении отчётов из БКИ, стратегии улучшения рейтинга, финансовое планирование.

Для когоСотрудники, планирующие крупные покупки

Мобилизационный юрист

  • Право
  • Гарантии

Помощь юристов при мобилизации: консультации по правам и гарантиям, бронирование, выплаты, взаимодействие с военкоматом, поддержка семьи мобилизованного сотрудника.

Для когоСотрудники и их семьи в период мобилизации

Здоровье и баланс

4 программы

Медицинский консьерж

  • Запись к врачу
  • Лекарства
  • Выплаты

Для когоВсе категории сотрудников, особенно с вредными условиями труда

Красивая улыбка

  • Стоматология

Консьерж-программа по стоматологии: диагностика, лечение, протезирование зубов. Организация лечения в партнёрских клиниках, частичная или полная компенсация.

Для когоВсе категории сотрудников

Полезное питание и «Полезная корзина»

  • Здоровье
  • Партнёры

Вебинары о питании как энергии жизни, доставка продуктов питания местного производства от партнёров. Поддержка здорового образа жизни в коллективе.

Для когоВсе категории сотрудников

Work-life balance

  • Баланс
  • Антистресс

Программа соблюдения баланса между работой и личной жизнью. Консультации по тайм-менеджменту, профилактика выгорания, практики восстановления, поддержка в условиях переработок.

Для когоСотрудники с высокой нагрузкой и ненормированным днём

Карьерный навигатор

  • Развитие
  • Наставничество
  • Кадровый резерв

Эффективное управление подчинённым сотрудником

  • Менеджмент
  • Обучение

Программа для руководителей: навыки постановки задач, обратной связи, мотивации, разбора конфликтов и работы с низкой производительностью.

Для когоНачальники цехов, участков, бригадиры

  • Команда
  • Медиация

Программа по улучшению психологического климата в бригадах и сменах. Медиация конфликтов, командообразование, работа с токсичным поведением.
